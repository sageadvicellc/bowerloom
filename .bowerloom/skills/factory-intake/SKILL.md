# Factory intake

Read the repository's AGENTS.md and FACTORY.md before selecting work.
Read the workbench Sage Ops standard before an authorized GitHub change.
A status request authorizes reads only.
An intake request collects candidates but does not authorize implementation.
Use existing bot tools for an authorized GitHub change.
Never post as Hanna or infer her approval from a bot reply.

For each candidate, record its source, repository, purpose, reproduction, acceptance criteria, prerequisites, and current owner.
Compare it with open tasks before creating another task.
Assign one owner only after that owner accepts the task.
If ownership, scope, access, or evidence is missing, return blocked with the missing prerequisite.
Start no substitute task without authorization.
Keep one primary delivery lane and one small friction lane.

For support work, reproduce the report before proposing a fix.
For a code defect, retain a failing test or explain why reproduction is blocked.
Route research questions and article candidates through factory-handoff.

Return the task, repository, owner, input revision, state, evidence, decisions, and next action.
