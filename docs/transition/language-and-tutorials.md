# Language and tutorials

Hanna requested Endor and Star Wars references on October 1, 2026. The inspiration is a connected settlement among trees. Each installation can grow independently and connect through explicit bridges.

Use this theme in tutorial titles, example workspaces, demo stories, and occasional success messages. Introduce the ordinary technical term beside each metaphor. Keep commands, schemas, permissions, errors, and approval text precise. The existing module names and Coda and Emery roles remain stable.

## Proposed tutorial vocabulary

| Reference | Ordinary meaning | Example |
|---|---|---|
| Tree | Independent Trellis installation | Start a personal installation |
| Treehouse | Workspace within an installation | Build your first treehouse |
| Bridge | Explicit, scoped connection | Connect to company knowledge |
| Village | Company team and its connected installations | Join the shared company workspace |
| Endor | Synthetic demonstration scenario | The Endor village demo |

The bridge metaphor must preserve permissions and ownership. Crossing a bridge grants only its stated access. Disconnecting from the village leaves personal work independent. A larger workspace does not gain more authority from its name.

## Proposed tutorial sequence

1. Build your first treehouse with the Codex-first alpha.
2. Ask Coda and Emery to complete a bounded local task.
3. Inspect the result, recorded progress, and acceptance instructions.
4. During beta, connect the personal installation to the company village.
5. Grant access to a selected knowledge collection through a bridge.
6. Disconnect and reconnect while preserving personal work and company task ownership.

Use original examples and illustrations. Star Wars references remain optional flavor within otherwise understandable instructions. A small “Yub nub” success message can follow the ordinary success result. Never replace an error, permission request, or recovery instruction with a reference.
