| Area | Approved alpha default | Boundary |
|---|---|---|
| Repository | Assemble the five modules in `sageadvicellc/trellis` | Preserve history and private-content boundaries before importing accepted work |

| Retrieval | Authorized keyword retrieval over synthetic sources | Establish embedding interfaces now; evaluate semantic retrieval for beta |
| Data | Synthetic demo inputs and optional telemetry disabled | No customer data or central telemetry collection in this campaign |
| Capacity | Existing subscriptions, two active workers, 25 percent reported reserve | Count lead and review usage; stop new model work when admission lacks reliable evidence |
| Language | Endor-inspired tutorials and examples | Preserve clear technical terms, stable interfaces, and explicit permissions |

An action broker is code that authorizes and dispatches operations. Workers cannot bypass it through native tools, subprocesses, or unmanaged network access. The team must demonstrate this boundary before claiming alpha readiness. A failure stops the affected capability while independent implementation work continues.
