# Sources

This folder holds your originals, saved just as they came: files, notes, transcripts, and pasted text.

- Name each file with the date it was made, then a short name. Example: `2026-01-31-garden-notes.md`.
- Do not edit a source after you save it. Pages hold what you learn from it. The source stays as proof.
- Ask the Notes keeper to add a source. It saves the file here, writes a page about it, and records the change.
