# Pages

This folder holds your notes. One page covers one subject.

- Name each file with a short name in lowercase, with hyphens. Example: `garden-plan.md`.
- Start each page with the four fields that `AGENTS.md` describes: title, created, updated, and sources.
- Link related pages to each other. Add every new page to `index.md`.
- Ask the Notes keeper to write or update a page. It finds out first if the page already exists.
