A personal setup prepares definitions for your existing agent. Shared company services are outside this local setup path.

## Ask your agent

```text
Explain current Bowerloom personal and company support. Explain which shared services are outside the documented setup path. Do not import real business data.
```

## Agent procedure

### Personal work

Read [the setup tutorial](/docs/learn/first-team/) and [current availability](/docs/status/). Optional local connections and registered controls require separate plans.

Local setup does not establish unattended autonomy. Review the actual owner, scope, and stop behavior before any execution.

### Shared company work

Local definitions do not enroll employees or provide company identity controls. Shared access, semantic retrieval, offboarding, and deletion are outside this beta's documented setup path. These docs provide no shared-company installation procedure.

### Real business data

Real business data requires an approved retention and deletion policy. The current documentation grants no business-data import or employee enrollment.

If a request needs shared access or real-data controls, establish those controls before importing data.
