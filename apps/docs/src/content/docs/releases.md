## v0.7-alpha

The published [source prerelease `v0.7.0-alpha.0`](https://github.com/sageadvicellc/bowerloom/releases/tag/v0.7.0-alpha.0) provides source archives. It does not contain a published npm package or compiled CLI installer.

Private development artifacts continue to report `0.7.0-alpha.0`. Exact source, archive and distribution hashes distinguish their reviewed behavior. A filename or version alone is not sufficient identity.

## v0.7-beta — in development

Required work includes an installable CLI, documentation, Codex and Claude Code, company/personal boundaries, MCP controls, retrieval, access lifecycle tests, and Workbench evidence.

This site is a documentation preview for that work. The [reviewed setup trial](/docs/status/#reviewed-setup-identity) is narrower than beta acceptance.

## Later milestones

`v1-beta` and `v1-rc` remain later release milestones. They are not available through these instructions.

Main merge, initial release publication, and production promotion remain founder decisions. Documentation publication does not itself grant runtime or support authority.
